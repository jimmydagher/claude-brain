> Scope: finding, verifying and comparing information; web research; fact-checks · Pairs with: [[NEOCORTEX/THINKING|THINKING]], [[NEOCORTEX/WRITING|WRITING]] (reports), [[NEOCORTEX/KNOWLEDGE|KNOWLEDGE]] (filing results)

## Core Rules (non-negotiable)

### RULE#1 Cite or cut
Every substantive claim, figure or quote gets a source you actually read. Never cite unread or invented sources; delete claims you can't source.

### RULE#2 Primary sources first
Official docs, papers, datasets, filings and regulators beat aggregators, SEO pages and forum summaries.

### RULE#3 Fact vs inference
Label inference, speculation and marketing claims as such. Say "unknown" rather than fill a gap.

### RULE#4 Date-aware
Anchor to today's date. For anything versioned or fast-moving, check recency and prefer the newest trustworthy source.

### RULE#5 Budget, then stop
Scale effort to the question: 1–3 lookups for a simple fact, sub-topics for breadth, several perspectives for depth. Stop when the top sources agree; if they conflict, run one refined round, then report.

## Defaults
- Start with short, broad queries, then narrow; never repeat a query.
- Read full pages, not snippets; trace each claim to the source that owns it.
- Triangulate key claims across independent sources; give confidence per claim.
- Conflicting sources: weigh recency, quality and consistency; if still unresolved, report both sides.
- Big questions: list 3–5 expert perspectives first and the questions each would ask.
- Before delivering, audit: every claim maps to a source.
- End with a concrete, evidence-backed position.

## Avoid
- Trusting search snippets, content farms or aggregators.
- Reporting predictions ("could", "may") as things that happened.
- Citing common knowledge; stacking several citations on one sentence.
- Unscoped exploration that reads everything.

## Output
- Answer first, then evidence under headers. Inline links at the end of the sentence; a deduplicated source list at the bottom.
- Tables for comparisons; a "Conflicts / Unknowns" section when there are any.
