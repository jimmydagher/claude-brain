# SDSI upkeep

Standing instructions from the `sdsi` plugin (1.3.15). Generated by `sdsi:upkeep` — to change one, edit the topic skill and run `/sdsi:upkeep` again; to drop one, run `/sdsi:upkeep` and remove its topic.

## sdsi:versioning

- Every code change → a bullet under the right subsection of `meta/CHANGELOG.md`'s Unreleased, written as it's made, for whoever deploys it (`sdsi:versioning`)
- Never commit unless the human asks — the human commits and the release hooks do the version, changelog, `TODO.md`, and message (`sdsi:versioning`)
- Handing a change over to commit → the whole of it staged (`git add -A`) or none of it, never a half-staged index — `git mv` and `git rm` stage only themselves (`sdsi:versioning`)
